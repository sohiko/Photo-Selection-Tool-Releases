# アルバム写真選別ツール

検査済みアプリと更新情報の配布用リポジトリです。写真・人物情報・選別結果・利用者の認証情報は含みません。

[最新版をダウンロード](https://github.com/sohiko/Photo-Selection-Tool-Releases/releases/latest)

Mac（Apple Silicon）とWindows（x64）に対応します。ZIPを展開し、Macは同梱の起動案内に従ってください。

1.4.0以降はアプリ内で更新を確認・取得し、「更新して再起動」で適用できます。1.3.1以前からは、最初の1回だけ更新機能付きの版をダウンロードしてください。

公開されている更新情報は署名されています。写真や選別結果の共有には、引き続き利用者自身のGoogleログインとGoogle Driveの権限が必要です。
